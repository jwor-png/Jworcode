# Meridian — understand and extend your engine
### A pack for John. Built with Shane, 29 July 2026.

You have run Meridian every day since 9 June. You know how to use it. This pack is about the next step: seeing your whole engine clearly, and being able to make it stronger yourself, without anyone sitting beside you.

Four documents, and the order to read them.

1. **01 — Meridian Map.** The anatomy of your engine. Your seven managers and all fifty skills sitting under them, on paper for the first time.
2. **02 — Meridian Wiring.** How the engine actually thinks. How one question moves through the managers, the floor that every answer stands on, and one real job traced end to end.
3. **03 — How to Write a Slice.** The template. Exactly how to add a new skill so it sits inside your system the same as its brothers. Seven steps, most of them seconds.
4. **04 — Six Slices to Add.** Six new skills, written and ready to paste. You add each one yourself using the template. One of the six is already live in the master engine; the other five are yours to add.

**The visual suite (three PDFs).** The Map, the Wiring and How to Write a Slice are also here as finished PDFs, the same three built to be shown, printed, or shared. Read the Markdown, show the PDFs.

**The upgrade (INSTALL - upgrade Meridian).** This file adds the six new skills to your engine and takes it from fifty to fifty-six. Open Meridian and say "read INSTALL - upgrade Meridian and apply the upgrade to yourself", and it will do it. Or paste the lines in by hand using document 03.

The whole craft is two things: knowing what you want, and knowing which manager it belongs to. Everything after that is a one-line paste.

AI driven, human led.
